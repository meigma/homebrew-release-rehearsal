# Meigma Release Rehearsal Tap

Disposable Homebrew tap used to rehearse cask publication for [`meigma/release`](https://github.com/meigma/release).

Install the rehearsal cask with:

```sh
brew install --cask meigma/homebrew-release-rehearsal/meigma-release-cli
```

This repository is temporary release-engineering evidence, not a supported package channel.
